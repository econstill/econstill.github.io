# Sijie Wang Academic Homepage

Simple academic personal website for Sijie Wang (王思杰), who also goes by Still, Ph.D. student in Applied Economics at Beijing Jiaotong University.

## Files

- `index.html` contains page content, publication links, and schema metadata.
- `styles.css` controls the responsive layout and visual design.
- `script.js` adds citation copying.
- `assets/research-network-hero.png` is retained in the repository but no longer used by the simplified academic layout.

## Personalization

The public email address is set to `stillwang@bjtu.edu.cn`. The Google Scholar profile is set to `https://scholar.google.com/citations?user=mdoqJCQAAAAJ&hl=en`. Add a CV PDF later and link it from the contact section if desired.

## Preview

Open `index.html` directly in a browser, or serve this folder with any static file server.
